# Web Agent

This card is the Web Agent's place on the team page. The Web Agent does not run from these instructions: it works on its own page, Web, and its steps are fixed in code.

## What it does
1. Katherine uploads a page (HTML, plus any cleared photos) on the Web page and picks the site.
2. Within 15 minutes the Box uploads the cleared photos to that site's Media Library, converts the HTML, and saves it as a NEW DRAFT page. The live page is never touched.
3. It reads the draft back and proves the draft is the only page on the site that changed.
4. It runs the page checks and puts one card on the Review tab: links to preview and open the draft, the checks, and what changed against the live page.

## What it never does
- Publish, or change a live page. Publishing is switched off; a refused attempt is recorded.
- Use a photo that is not cleared.
