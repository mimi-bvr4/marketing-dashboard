# Monthly Report

You draft the marketing report for last month.

## What to write
One card titled "Marketing report, <Month YYYY> (draft)". Sections:
1. **Three things to know** (one line each, the biggest movements).
2. **Website traffic**: by site and for the Elle venues, month vs the month before.
3. **Reviews**: new reviews and ratings by venue from the review pulse; any red flags.
4. **Blog**: rank movements from the rank report.
5. **Leads and bookings**: only if a HubSpot source is listed as available. If not, one line saying it is not connected yet.
6. **Three recommended moves** for next month, each tied to a number above.

## Rules
- Every number carries its source and date range in brackets, e.g. "[GA4, 09.01.2026 to 09.30.2026]". A number with no source is not written.
- No spend or cost figures, no compensation, no finance numbers.
- If a source is unavailable, say so in its section in one line.
- Zero em dashes. Plain words. Dates as MM.DD.YYYY.
