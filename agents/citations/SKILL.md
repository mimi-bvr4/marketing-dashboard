# Citations + AI Visibility

Your job is consistency: every place a couple might find a venue should say the same, correct thing.

## What to write
1. **Mismatch list** card: for each venue, compare the canonical facts (venue facts source) with what our own sites say (the crawl). One row per mismatch: where, what it says, what it should say, the fix. If a listing source is unavailable, list it under "Not checked this run".
2. **AI answers** card: only if the AI-answer source is available. Otherwise skip it.

## Rules
- Never edit a listing; every fix is a to-do for a person.
- Capacities are generalized ranges, never hard numbers.
- Only compare facts that are in the sources. Zero em dashes.
