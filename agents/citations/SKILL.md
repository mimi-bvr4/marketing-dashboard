# Listings + Citations

Your job is that every place a couple might find a venue says the same, correct, current thing.

## What to write
1. **Mismatch list** card: for each venue, compare the canonical facts (venue facts source) with what our own sites say (the crawl) and with the directory listings draft. One row per mismatch: where, what it says, what it should say, the fix. The listings draft is unconfirmed until Katherine confirms which are paid and who owns each login; mark listing rows "(draft list)". If a source is unavailable, list it under "Not checked this run".
2. **AI answers** card: from the AI assistant answers source (Claude, ChatGPT, Gemini and Perplexity, asked monthly on the 15th per Mimi's ruling of 10.12.2026). For each assistant and venue, compare the answer with the canonical venue facts (name, city, venue type). One row per problem: assistant, venue, what it said, what is true, the likely fix (usually a listing or page to correct). Note venues an assistant did not know or left out of a category answer. List any assistant marked skipped under "Not checked this run". If the source is unavailable, skip this card.
3. **Where AI gets its answers** card (ORDER #1715, Mimi 10.13.2026): from the "pages AI assistants cite" source, which is measured. Lead with the sites cited for the most searches that name NONE of our venues: those are the gap. For each, one line: what the site is (a marketplace like Peerspace or Giggster, a directory like Cvent or PartySlate, a local guide or blog, a list article), and the human to-do: claim or create our listing, update a listing that exists, or pitch the editor to add our venue (PR Patty can draft the pitch). Then the cited sites that DO name us, and whether the facts there match the canonical source. Never claim a site mentions us unless the table says so. Marketplaces that rent space by the hour (Peerspace, Giggster, Swimply) are a business decision for Katherine and Mimi, so say so instead of recommending a listing.
4. **Refresh packs**, only when TODAY is in January, April, July or October, or when the request asks for them: "Refresh pack: <venue> on <directory>", one per listing in the directory listings draft, as many as the card limit allows (most out of date first; say which are left for next run). Each: a new description within that directory's length limit, 10 photo picks (described, to pull from the archive) with alt text, generalized guest-range language, and a short review-request message a coordinator can send to a recent happy couple. Use the newest review pulse for what couples praise. Fix in the pack anything card 1 found wrong for that listing.

## Rules
- Never edit a listing, never log in to a directory, never use a person's login; every fix is a to-do for a person.
- Work only from the directory listings draft for listings. It is a draft until Katherine confirms which listings are paid and who owns each login; say so on each card that uses it.
- Prices only as "starting at" and only from a source Katherine approved; never from HubSpot.
- Capacities are generalized ranges, never hard numbers.
- Only compare facts that are in the sources. Never repeat an assistant's claim as fact. Zero em dashes.
