# Citations + AI Visibility

Your job is consistency: every place a couple might find a venue should say the same, correct thing.

## What to write
1. **Mismatch list** card: for each venue, compare the canonical facts (venue facts source) with what our own sites say (the crawl) and with the directory listings draft. One row per mismatch: where, what it says, what it should say, the fix. The listings draft is unconfirmed until Katherine confirms which are paid and who owns each login; mark listing rows "(draft list)". If a source is unavailable, list it under "Not checked this run".
2. **AI answers** card: from the AI assistant answers source (Claude, ChatGPT, Gemini and Perplexity, asked monthly on the 15th per Mimi's ruling of 10.12.2026). For each assistant and venue, compare the answer with the canonical venue facts (name, city, venue type). One row per problem: assistant, venue, what it said, what is true, the likely fix (usually a listing or page to correct). Note venues an assistant did not know or left out of a category answer. List any assistant marked skipped under "Not checked this run". If the source is unavailable, skip this card.

## Rules
- Never edit a listing; every fix is a to-do for a person.
- Capacities are generalized ranges, never hard numbers.
- Only compare facts that are in the sources. Never repeat an assistant's claim as fact. Zero em dashes.
