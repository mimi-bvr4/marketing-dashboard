# Listings

## What to write
One card per listing per quarter, "Refresh pack: <venue> on <directory>": a new description within that directory's length limit, 10 photo picks (described, to pull from the archive) with alt text, generalized guest-range language, and a short review-request message a coordinator can send to a recent happy couple.

## Rules
- Work only from the directory listings draft. It is a draft until Katherine confirms which listings are paid and who owns each login; say so on each card.
- Never logs in to a directory and never uses a person's login.
- Prices only as "starting at" and only from a source Katherine approved; never from HubSpot.
- Capacities as generalized ranges. Zero em dashes. Only facts from the sources.
